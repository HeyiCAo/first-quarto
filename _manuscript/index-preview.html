1 Who I Am

I’m Heyi Cao, a student at UW–Madison studying computer science. Although computer science is my main academic focus, many of my interests also involve visual and creative work, especially photography, aviation, and 3D design.

I am taking this course because I want to build the skills necessary for future research. In particular, I hope to learn how to approach problems in a more systematic way: identifying a question, collecting and organizing evidence, testing possible explanations, and communicating results clearly. I also want to become more comfortable with tools and workflows that support reproducible research, so that my work can be understood, checked, and built upon by others.

2 If I Were a Package

If I were a Python package, I would be NumPy. According to the official NumPy documentation, NumPy is a fundamental package for scientific computing in Python (NumPy Developers 2026).

  1. I identify with it because it provides a foundation for many different kinds of work:
    • data analysis
    • scientific computing
    • machine learning.
  2. NumPy has also become an important foundation for scientific computing in the Python ecosystem (Harris et al. 2020). I also value building strong fundamentals and creating something that others can use as a foundation for their own work.

3 NumPy Demonstration

In [1]:
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 2 * np.pi, 100)
y = np.sin(x)

plt.plot(x, y)
plt.xlabel("x")
plt.ylabel("sin(x)")
plt.show()

As shown in Figure 1, NumPy can generate and transform numerical data that can then be visualized clearly.
